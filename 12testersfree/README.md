# 12TestersFree

Proyecto Android nativo en Kotlin. Primera estructura con cuatro pantallas navegables, interfaz bilingüe español/inglés y configuración Gradle inicial.

**Estado:** interfaz local inicial. No hay autenticación, anuncios ni recompensas reales todavía. Ningún saldo o prueba se acredita sin validación del servidor.

**Compilación:** Android SDK 35, JDK 17 y Gradle 8.7. El wrapper de Gradle y la compilación AAB aún están pendientes de validación.

**Siguientes fases:** backend gratuito independiente, Google Sign-In, RLS y transacciones de monedas, biblioteca y publicaciones, pruebas y anuncios. No incluir claves privadas en el repositorio.
